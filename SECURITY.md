# Security Policy

## Reporting Security Vulnerabilities

If you discover a potential security vulnerability within Sunya Visibility (such as credential exposure, rate limit bypass, or injection vectors), please do **NOT** open a public issue.

Instead, please send a private email directly to the project maintainer:

- Email: **basantpok90@gmail.com**
- Subject: `[SECURITY] Potential Vulnerability in Sunya Visibility`

Please include:

1. Description of the vulnerability
2. Steps to reproduce
3. Potential impact

We take all disclosures seriously and will respond promptly.
